# Concessionária - Front-end

Projeto Front-end desenvolvido em Angular.

## Executar

1. Instale o Node.js.
2. No terminal, entre nesta pasta.
3. Execute `npm install`.
4. Execute `npm start`.
5. Acesse `http://localhost:4200`.

## Comunicação com o Back-end

O serviço de clientes utiliza a API:
`http://localhost:8080/api/clientes`

Portanto, para o sistema funcionar completamente, o Back-end deve estar executando separadamente na porta 8080.
